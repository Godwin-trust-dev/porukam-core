# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue.

- Use GitHub private vulnerability reporting: the "Report a vulnerability" button on the Security tab of this repository.
- Or write to hello@trust-dev.com.

Include the affected component, steps to reproduce, and the impact you see. We acknowledge reports and keep you informed about the fix. Please give us reasonable time to fix the issue before public disclosure.

## Scope

This repository (backend, web app, packages). Issues in third-party dependencies should be reported to their maintainers; tell us as well if Porukam is affected.

## Secrets

The repository contains only development defaults and test values. If you find what looks like a real secret, report it as a vulnerability.
