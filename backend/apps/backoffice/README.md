# apps.backoffice

Служебный доступ операторов платформы (backoffice): внутренние роли и админ-операции. Не относится к сторонним исполнителям.

Заглушка каркаса (этап 1 плана). Реализация — по docs/tech-spec.md §4 и §10.3. Переименовано из прежнего имени приложения по ADR-203 (терминологическая красная линия); Django-поле `is_staff` и `/admin/` — системные, не затронуты.
