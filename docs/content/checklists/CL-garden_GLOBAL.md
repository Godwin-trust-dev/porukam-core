# CL-garden (GLOBAL) — Шаблоны чек-листов приёмки и справочник материалов

> **Партия 3 задачи П-03, GLOBAL-формат.** Сфера 2: `garden` — Сад и благоустройство участка.
> Категорий: 5 (+ `garden.other`). Формат и GLOBAL-правила — `00_индекс.md` §2. Модель приёмки: поэтапная + сезонные оговорки (приживаемость — при соблюдении заказчиком графика полива; док 18 S2). Доказательный минимум: фото участка «до», фотофиксация трасс/дренажа до засыпки, посадочная ведомость, переданные инструкции по уходу.
> **Статус ревью: ⏳ ожидает ревью владельца.**
