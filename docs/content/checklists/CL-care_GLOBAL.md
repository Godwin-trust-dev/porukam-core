# CL-care (GLOBAL) — Шаблоны чек-листов приёмки

> **Партия 6 задачи П-03, GLOBAL-формат.** Сфера 14: `care` — Уход и присмотр.
> Категорий: 3 (+ `care.other`). Формат и GLOBAL-правила — `00_индекс.md` §2.
> ⚠ **Сфера с максимальным риском переквалификации в трудовые отношения** (док 15 §8). Лексика строго подрядная: разовые/периодические **услуги по договору**, оплата за визит/результат по акту. Критерии — только факты: журнал визитов, отчёты, отметки времени. Модули V-EMPL и V-CHILD обязательны (док 18 S14).

### 1.4. `care.other` — Прочее

Чек-лист пишется сторонами с нуля. Универсальный каркас сферы: (1) визиты по журналу с отметками времени; (2) регламент заказчика выполнен — отметки по пунктам; (3) отчёт по каждому визиту/периоду; (4) инциденты фиксируются и сообщаются немедленно; (5) конфиденциальность сведений о семье — бессрочно. Лексика — только «исполнитель/услуги/вознаграждение по договору».
