## 0. Формат и маппинг на модель данных

**Коды.** Полный код категории = `renovation.<категория>`. Полный код пункта = `renovation.<категория>.<код пункта>`, где `<код пункта>` = `<тип_работ>.<номер>` (например, `renovation.tiling.wall_tiling.1`). Пункты `common.*` — расширенный набор категории: предлагаются для любого типа работ этой категории.

**Маппинг на `ChecklistTemplateItem`:** `code` = полный код пункта · `text` = формулировка · `check_method` = как проверить · `photo_required` = фото · `is_default` = дефолт (пункт предзаполняется при выборе типа работ; «нет» = расширенный набор, предлагается по кнопке «добавить из шаблона»). `Category.baseline_checklist` = строка «Базовый чек-лист категории (топ-5)» — предзаполнение этапа, когда тип работ не выбран.

**Словарь «как проверить»** (enum `check_method`, 6 значений):

| Значение | Что означает |
|---|---|
| `осмотр` | визуальная проверка, в т.ч. с фонариком, с расстояния, сверка с образцом/фото «до» |
| `замер` | инструментальная проверка: правило 2 м, уровень, рулетка, термометр, розеточный тестер, лист бумаги, шумомер |
| `включение` | проверка в действии: запуск, открывание/закрывание, проход, нагрузка рукой, контрольный прогон |
| `пролив` | проверка водой/давлением: пролив точек, запруда, опрессовка, поведение после дождя |
| `документ` | передан документ/схема/акт/паспорт/комплект ключей — фиксируется в сделке |
| `фото` | фотофиксация в сделке: «до», скрытые этапы, «до/после» (стыкуется с ADR-036/053) |

**Правила чек-листов** (из док 16 + GLOBAL-дельта П-03 §7): 3 пункта по умолчанию, 4–5 — где безопасность; каждый пункт — измеримый критерий, проверяемый бытовыми средствами; числовые допуски — продуктовая рекомендация платформы (источники-нормативы хранятся в слое локали, в формулировках не упоминаются); пункты с пометкой **[Л]** зависят от местных правил и настраиваются юрисдикцией (JurisdictionConfig). Пункт в договоре — замороженная копия шаблона.

**Глоссарий терминов для перевода** (единообразны во всех пунктах; см. также 00_индекс §2): *2-метровое правило* — жёсткая ровная рейка длиной 2 м для проверки плоскости; *просвет* — зазор между правилом и поверхностью; *УЗО* — устройство защитного отключения (RCD); *люфт* — ощутимый свободный ход/качание; *примыкание* — стык двух поверхностей/конструкций; *затирка* — заполнение швов между плитками; *пролив* — контрольная подача воды; *фото «до»* — фотофиксация состояния до начала работ, переданная в сделку.

**Доказательный минимум сферы** (док 18 §6, S1) — отражён пунктами с фото=да: фото «до» помещения (`common.1`), фотофиксация каждого скрытого этапа до закрытия (пункты скрытых работ в wiring, water_pipes, waterproofing, thermal_insulation, soundproofing, strip/slab/pile_foundation, facade_insulation, drainage-аналоги, UFH и др.), сверка повреждений с фото «до» (`common.3`), допработы только допсоглашением (`common.4`).
