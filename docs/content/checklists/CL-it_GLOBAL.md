# CL-it (GLOBAL) — Шаблоны чек-листов приёмки

> **Партия 4 задачи П-03, GLOBAL-формат.** Сфера 7: `it` — IT и разработка.
> Категорий: 7 (+ `it.other`). Формат и GLOBAL-правила — `00_индекс.md` §2. Модель приёмки: соответствие ТЗ, окно на мотивированный отказ, лимит раундов правок K; результат сдан только вместе с исходниками и доступами (док 18 S7). Причины споров (док 15 §2): нет ТЗ, сдача «в чат», непередача доступов, устные изменения объёма.
> N (варианты) и K (раунды правок) — переменные договора; «нравится/не нравится» не является критерием приёмки.
> **Статус ревью: ⏳ ожидает ревью владельца.**
