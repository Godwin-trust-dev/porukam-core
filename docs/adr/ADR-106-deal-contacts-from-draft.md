# ADR-106. Контакт source=deal — с черновика, через outbox

Дата: 2026-08-21. Статус: принято.

## Контекст

Отсмотр 2026-08-21: «при начале работы с договором контрагент должен попадать
в сохранённые контакты». `Contact.Source.DEAL` был заведён в tech-spec.md
§5.2.1b «на этап 4», но ни одно место его не создавало.

Ограничения: `apps.social` по import-linter зависит только от `apps.accounts`
и не может читать `apps.contracts`; Django-сигналы запрещены (CLAUDE.md);
контакт — приватное ребро владельца, засорять контакты второй стороны без её
действия нельзя.

## Решение

1. `apps.contracts` кладёт в payload событий `contract.drafted`,
   `contract.draft_patched`, `contract.signed` список `party_user_ids` —
   `owner_user_id` person-профилей сторон. Бизнес-профиль (юрлицо) в список
   не попадает: у него нет пользователя-контакта.
2. `apps.social.subscriber.handle_event` (зарегистрирован в
   `OUTBOX_SUBSCRIBERS`) создаёт `Contact(source=deal)`:
   - `drafted` / `draft_patched` — **только у инициатора (actor)** на
     контрагента: решение пользователя «по черновикам», вторая сторона ещё
     ничего не сделала;
   - `signed` — обоюдно: подпись — действие обеих сторон.
3. Идемпотентность — уникальность `(owner, target_user)`: повтор события и
   уже существующий контакт любого источника (manual/phonebook/link) не
   трогаются, источник не «понижается» до deal.

## Отвергнуто

- Прямой вызов `social.services.add_contact` из `contracts.services` —
  направление зависимости допустимо (contracts → social), но контакт не
  инвариант договора, а побочный эффект; outbox даёт ретраи и симметрию с
  `apps.profiles.subscriber`.
- Добавлять обе стороны уже на черновике — отвергнуто как шум у контрагента.

## Последствия

- Фронт: раздел контактов получает записи с `source=deal` без изменений API.
- Удаление контакта пользователем (`DELETE /users/me/contacts/{id}`) не
  отменяется следующим событием того же договора? **Отменяется**: новый
  `draft_patched`/`signed` вернёт контакт. Принято как допустимое для
  запуска; если будет мешать — добавить `Contact.removed_at` с memory-эффектом.
