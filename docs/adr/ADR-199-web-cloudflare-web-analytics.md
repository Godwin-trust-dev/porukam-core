# ADR-199. Статистика посещений сайта — Cloudflare Web Analytics

**Статус:** принято (владелец 2026-11-04: «GA отменяй… переходим на Cloudflare Web Analytics»)
**Контекст:** `web/index.html`, `web/scripts/prerender.mjs`, `docs/legal/*/privacy.md`
**Номер:** 199 — следующий за 198 по всем веткам (сверено `ls ~/porukam-worktrees/*/docs/adr`).

## Контекст

Собственная аналитика (ADR-145, ADR-171) видит только то, что доходит до бэкенда: вход,
договоры, установки. Кто открыл лендинг и ушёл, откуда пришёл, с какого устройства — не видно
нигде. Отчёты Cloudflare по зоне этого тоже не покажут: `porukam.app` в сером облаке
(ADR-174 (внутренний ADR, не публикуется)), через Cloudflare идёт только `www`, а его edge-правило отвечает 308 — в панели
одни редиректы.

## Решение

JS-сниппет Cloudflare Web Analytics (сайт `porukam.app`, ручная установка — для серого
облака автоматическая не работает) вставлен дословно в `<head>` шаблона оболочки
`web/index.html`. Пререндер берёт `dist/index.html` как шаблон для `landing.html` и всех
публичных страниц (ADR-195), так что скрипт один на весь сайт, включая SPA и TWA. Переходы
по History API маяк считает сам.

Токен публичный (виден в HTML любой страницы), поэтому лежит в git, а не в env.

## Почему не Google Analytics

Рассматривался и был отменён в тот же день. Cookie-баннер обещает «по умолчанию только
необходимые», баннер стоит только на `/welcome` — почти все посетители лендинга остались бы
без согласия, GA в Consent Mode получил бы от них обезличенные пинги, а моделирование Google
при нашем трафике не включается: отчёты были бы почти пустыми. При этом GA требовал переписать
§8 политики, уведомление до вступления в силу (§14) и переключатель отзыва согласия в
настройках. Cloudflare Web Analytics не ставит cookie и ничего не хранит на устройстве —
баннер и согласие не нужны, а Cloudflare уже наш поставщик (политика §7).

## Последствия

- Политика конфиденциальности: в EN (эталон) и RU Cloudflare в таблице §7 получил «статистику
  посещений без cookie», в §8 вместо обещания «если появится аналитика — сначала отразится
  здесь» — абзац о том, что именно получает Cloudflare. Номер версии остаётся 1.0, остальные
  27 машинных переводов НЕ обновлялись (решение владельца 2026-11-04: «не надо переводить») —
  они расходятся с эталоном в §5/§7/§8; при расхождении действует EN (docs/legal/README.md п. 1).
- Блокировщики рекламы режут `cloudflareinsights.com` — цифры занижены; для решений смотреть
  тренды, а не абсолютные значения.
- Если у сайта появится CSP — разрешить `static.cloudflareinsights.com` (script-src) и
  `cloudflareinsights.com` (connect-src).
- В настройках сайта в панели Cloudflare НЕ включать автоматическую вставку: при оранжевом
  облаке она добавила бы второй маяк и двойной счёт.
