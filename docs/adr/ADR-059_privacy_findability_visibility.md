## 0. Решения финализации (01.08.2026, утверждены владельцем)

| # | Решение | Итог |
|---|---|---|
| Р1 | Уровни доступа к карточке | **Два уровня в Р1**: `public` / `link_and_deals` («только по прямой ссылке и в сделках»). Расширяемый enum |
| Р2 | Тумблер «скрыть из каталога при заявленной сфере» | Остаётся, дефолт Выкл |
| Р3 | Имя | Дефолт — показывать; тумблер «показывать только @handle». Контрагент по сделке всегда видит верифицированное имя (основа — исполнение договора, не согласие) |
| Р4 | Аватар | Открыт (в составе согласия на распространение); тумблер «аватар только контрагентам»; без фото — генерируемый плейсхолдер от @handle |
| Р5 | Раздельная видимость профилей | **Раздельная**: бизнес-профиль публичен всегда, пока активен (вместо скрытия — деактивация); физлицо-профиль управляется Р1–Р4 |
| Р6 | Геолокация | API никогда не отдаёт координаты — только название города; «рядом со мной» считается на сервере; точность в Р1 — город; «работаю удалённо» — отдельное булево поле |
| Р7 | Находимость по телефону | **Явный выбор без предустановки** на шаге согласий; «да» — рекомендуемый вариант; молчание/пропуск = «нет»; логируются значение + версия текста + timestamp |
| Р8 | Хеши телефонной книги | Консервативно: **хеш = ПД**. Только хеши (сырой номер → 422); матчинг только против явно согласившихся; **несматченные хеши удаляются в транзакции сверки** |

**Юр-форма «публичности по умолчанию» (одобрена владельцем 01.08):** публичность и находимость — **явные согласия в окне при регистрации**, галочки ставит сам пользователь, ничего не предзаполнено. Три отдельных согласия (ФЗ-156 с 01.09.2025 — согласие отдельным документом; ст. 10.1 152-ФЗ — распространение, «молчание ≠ согласие»): (1) обработка ПД; (2) публичность профиля (= распространение; рекомендуемый вариант, отказ → `link_and_deals`); (3) находимость по телефону. Тумблеры видимости полей — механизм «запретов по категориям» ст. 10.1. Тексты экранов и источники — док 26 §1, §4.

## 1. Контекст

Базовый разворот: **раньше исходили из «профиль приватен по умолчанию», решили — наоборот.** Финализация 01.08 добавила юридическую форму: «по умолчанию» = рекомендуемый явный выбор, а не молчаливый пресет (§0).

## 2. Ключевой принцип: публичность — рекомендуемый путь, приватность — настройка

**Профиль публичен и находим — это рекомендуемый и подсвеченный путь**, который пользователь выбирает явным действием при регистрации (окно согласий, ~5 секунд). Ценность платформы — репутация как история обещаний — требует видимого профиля, и мы честно объясняем это на экране выбора. Приватность — осознанная настройка (сужение в любой момент).

**Исключение (ADR-042):** карточка юрлица без подтверждённого контроля инертна — защита от захвата, не приватность.

## 3. Настройки видимости (→ тумблеры личного кабинета)

| # | Настройка | Дефолт | Статус | Заметка |
|---|---|---|---|---|
| 3.1 | **Уровень доступа**: `public` / `link_and_deals` | `public` (по явному согласию) | ✅ Р1 | Enum расширяем |
| 3.2 | **Находимость по телефону** (хеши) | явный выбор, «да» — рекомендуемый | ✅ Р7 | Выключаемо; обоюдно |
| 3.3 | **Показ в каталоге/поиске** (по проф.сферам) | Вкл (в составе публичности) | ✅ | Сферы — при регистрации |
| 3.4 | **«Скрыть из каталога при указанной сфере»** | Выкл | ✅ Р2 | Только ссылка/@handle |
| 3.5 | **Видимость полей**: имя, аватар, портфолио, локация | §5 | ✅ Р3/Р4 | = запреты ст. 10.1 |
| 3.6 | **Геолокация** | город; координат нет | ✅ Р6 | §6 |

**Всегда доступно, не выключается:** прямая ссылка/QR · `@handle` · раскрытие в контексте сделки.

## 6. Геолокация — финал (Р6)

API отдаёт только название города; координаты не покидают сервер. «Рядом со мной» — серверный расчёт, расстояния не раскрываются. Точность Р1 — «город» (район — будущее значение enum). Метка «работаю удалённо» — отдельное поле, попадает в выдачу любого города. Механика поиска — в спеке экрана каталога.

## 7. Гость и стартовая карточка

Гость видит стартовую карточку (витрина фактов); состав — в спеке карточки репутации §14 п. 2.
