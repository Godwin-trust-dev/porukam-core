# ADR-114. Раздел «Поиск»: люди и объединения, гео-зоны v1

Дата: 2026-08-23. Статус: принято.

## Контекст

Отсмотр 2026-08-23: «Поиск по географии: по умолчанию локация человека,
либо зона (Весь мир, страна, округ, город). У объединения свой хендл, по
нему тоже можно искать».

## Решение

1. **`GET /v1/dashboard/search?q=&zone=`** — read-only кросс-агрегат по
   прецеденту ADR-090/109 (люди — profiles/accounts, объединения — social).
2. **Люди ищутся ТОЛЬКО по @хендлу и телефону.** Поиска по имени НЕТ BY
   DESIGN: ФИО хранится зашифрованным (envelope encryption,
   crypto-shredding — CLAUDE.md) и не индексируется. Хендл-поиск уважает
   `discoverable_by_handle` и каталожное скрытие (`hide_from_catalog`,
   видимость public); **телефон** — по явному согласию
   (`User.discoverable_by_phone`, шаг «Данные и приватность»), и это
   согласие сильнее каталожного скрытия (человек сам дал номер — он ждёт,
   что его найдут). Совпадение — по последним 10 цифрам.
3. **Объединения** — по имени (подстрока) и @хендлу (префикс), только
   публичные витрины; в выдаче handle/kind/join_policy/members_count.
4. **Гео-зоны v1: `world | country | city`.** Страна — `User.country_code`,
   город — `Profile.city_name` (строковое сравнение без регистра). Зона по
   умолчанию — самая узкая доступная у зрителя (город → страна → мир);
   запрошенная зона без данных сужается так же и возвращается как
   `applied_zone`. **«Округ» отложен**: в модели нет гео-справочника
   (регионы/районы) — появится вместе с ним, форма ответа не изменится.
   Браузерная геолокация → город потребовала бы внешний reverse-geocoding —
   отклонено (внешний сервис + ПД координат), локация = профиль.
5. Гео-фильтр применяется к людям; объединения без локации в v1.

## Отклонено

- Поиск по имени через отдельный незашифрованный индекс — размен приватности
  (crypto-shredding перестаёт покрывать имя) ради удобства; нет.
- PostGIS/радиусы — нет координат и справочника; текстовые зоны достаточны v1.

## Последствия

- Фронт: /search — строка запроса + переключатель зоны, две секции выдачи.
- Плейсхолдер поиска объясняет: «@хендл, телефон или название объединения».
